# Changelog

## Unreleased

Nothing has been released yet. So far:

- A swipe keyboard for Android, in French and English at once, on AZERTY and QWERTY, with emoji and inline password suggestions.
- A decoder that reads gestures with geometry and a very small on-device network, then uses the sentence to rank and revise words.
- A memory of corrections, encrypted on the phone, which leaves RAM whenever the keyboard hides.
- No permissions, no network code and no telemetry, checked on every release by `tools/check-release.sh`.
- A public release mode without tracing, third-party notices in Settings, CI for what needs no private data, and a training pipeline for public gestures.
